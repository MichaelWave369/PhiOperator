# PhiOperator Roadmap

## Rung 1 — complete
Retro terminal, nine-question training test, three disciplines, safe education and MIT engine.

## Rung 2 — this PR
Six ranks with nine scenarios each (54 unique trials), separate Standard and Chaos paths, offline import/export Passport, theme rewards, a reusable progression engine, unit tests and documented future host contracts.

## Rung 3 — planned
Opt-in adapters for PhiOS, PhiOS-Mobile, Gen.E.Wrist, PhiSurf and other creative tools. Authorable and localized challenge packs, including larger per-discipline expansion paths.

## Rung 4 — planned
Branching adventures, interactive fake DOS/Y2K Easter egg, more cosmetic challenges, restoration exercises and future Passport version migrations.

## Never
Use quiz scores for identity, intelligence, essential access or permissions. Treat host security as independent. Do not claim host integrations are installed until each host repo actually supports them.

## Rung 5: Living Operator Academy
- Three six-node interactive racks, 3 phases per incident, 3 virtual actions per phase
- Evidence inspection, misleading tests, simulated corrective tools and Chaos branches
- Local incident log and fully offline field reports
- Six optional Academy badges in Passport v1 namespaced extension
- Old question packs, Portable Passport SDK and other apps' rank-only imports remain compatible
- Future: update other host adapters to preserve namespaced Academy badges on re-export


## Rung 6: The Operator's World
- Nine connected rooms grouped into 3 sectors, navigated across explicit corridors
- Progressive unlocking, persistent fictional repair state and subsystem dependencies
- Final 3-check Nexus test with true recovery, mixed and Chaos endings
- PATCH-9 diagnostic companion, funny Chaos incidents, secret complaints annex
- Local World Save v1 with JSON export/import, bounded validation and reset
- Optional Standard/Chaos World medals added to Passport v1 Academy extension
- Preserves the Rung 1–5 play modes and no-security-escalation charter
- Future: more authored maps and a host-side reward viewer, preserving offline support
