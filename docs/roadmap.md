# PhiOperator Roadmap

## Rung 1 (this PR): A real toy with real lessons

- Static, responsive terminal experience with nine deterministic scenario questions
- Three pillars: Observe, Verify, Recover
- Contextual explanations and reusable engine
- Optional certificate / academy flow without lockouts
- Critical-action confirmation API with fail-closed unknown operations
- Local-only runtime, accessibility, tests and MIT license

## Rung 2: Sierra-style expansion packs

- More absurd scenarios, inclusive localization, authorable content packs
- Validated manifests with schema, versioning, reviewable source
- Y2K easter egg interactive fake DOS boot (clearly labeled simulation)
- Story branching, badges that do NOT unlock essential functions

## Rung 3: Cross-ecosystem adapters

- ΦOS launcher panel and PhiOS-Mobile responsive flow
- Gen.E.Wrist / PhiSurf hotkey entrypoint
- Embeddable training component and optional API callback
- Shared style tokens without importing global CSS

## Rung 4: Real operator safeguards

- Human-readable impact previews for irreversible actions
- Platform-enforced authorization, audit and undo when appropriate
- Restore rehearsals and configuration recovery exercises

## Never

- Infer intelligence, disability, identity, or worth from quiz outcomes
- Block safety-critical or necessary features because a user guessed wrong
- Use ideology or opinions as a test of fitness
- Let a client-side quiz stand in for privilege enforcement
- Send private responses to a remote leaderboard without informed opt-in
