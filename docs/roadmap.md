# PhiOperator Roadmap

## Rung 1 — complete
Retro terminal, nine-question training test, three disciplines, safe education and MIT engine.

## Rung 2 — this PR
Six ranks with nine scenarios each (54 unique trials), separate Standard and Chaos paths, offline import/export Passport, theme rewards, a reusable progression engine, unit tests and documented future host contracts.

## Rung 3 — planned
Opt-in adapters for PhiOS, PhiOS-Mobile, Gen.E.Wrist, PhiSurf and other creative tools. Authorable and localized challenge packs, including larger per-discipline expansion paths.

## Rung 4 — planned
Branching adventures, interactive fake DOS/Y2K Easter egg, more cosmetic challenges, restoration exercises and future Passport version migrations.

## Never
Use quiz scores for identity, intelligence, essential access or permissions. Treat host security as independent. Do not claim host integrations are installed until each host repo actually supports them.
